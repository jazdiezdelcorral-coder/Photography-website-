# Photography-website-
A photography website with my photos and my portfolio.

## What's here
- `index.html` — the page: hero, filterable portfolio gallery, about, contact
- `styles.css` — the look (dark, minimal, gold accent)
- `script.js` — gallery filters, full-screen lightbox (arrow keys / Esc), mobile menu
- `images/` — put your own photos here

## Make it yours
1. Replace every **"Your Name"** / **"Your City"** in `index.html`.
2. Add your photos to `images/` and change each `src="https://picsum.photos/..."` to e.g. `src="images/sunset.jpg"`.
   Set `data-category` on each `<figure>` to `landscape`, `portrait` or `street` (or add your own filter buttons).
3. Replace `you@example.com` and the Instagram link with your own.

## Put it online (free, GitHub Pages)
Repo **Settings → Pages → Build and deployment → Deploy from a branch**, pick the branch and `/ (root)`, save.
Your site will be at `https://<your-username>.github.io/Photography-website-/`.

## Preview locally
Just open `index.html` in a browser.
